# cat-invaders
Space invaders but it is a cat defending against rats


Hi! This is a project for Hack Club Terra in which I utilized the ncurses library as I havent in a long time. Because of that, expect bugs or not the best of optimization, if you have any tips: contact me!

Also if the game imidiatelly exits, resize your terminal to be bigger!


!windows only!
To play the game, download either the .exe file or the zip, and run it. Dismiss any warnings that windows may give you and run the program;

~0> - mice
@ - bombs
hastags - powerups
=^. .^= - cat
^ - bullets

made by pav, feel free to use this code as a base for your own game or for just making a reskin of it!
